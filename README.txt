JEXALI MVP PROTOTYPE

Open index.html in a browser.

Included:
- Home
- Shop
- Seller product posting
- Seller dashboard
- Cart
- Demo 10% Jexali marketplace fee calculation
- Browser-only storage via localStorage

IMPORTANT:
This is a front-end prototype, not a production marketplace.
It does NOT yet include:
- Real user accounts/login
- Real database
- Secure image uploads
- Real checkout/payment processing
- Seller payouts
- Taxes/shipping
- Admin moderation

For a real marketplace, the next phase should connect a backend/database and a marketplace payment provider such as Stripe Connect.
